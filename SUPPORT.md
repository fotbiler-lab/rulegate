# RuleGate Support

RuleGate 1.0 is a stable open-source project maintained on a best-effort,
community basis. Stable describes the public API and package line; it does not
imply a service-level agreement or guaranteed response time.

## Usage questions

Use the
[usage-question form](https://github.com/fotbiler-lab/rulegate/issues/new?template=question.yml)
for:

- Installation questions
- Manifest design questions
- ASP.NET Core integration questions
- Authorization modeling guidance
- Claims or resource-mapping questions
- Diagnostics and logging questions
- General troubleshooting

Before opening a question:

- Read the README and relevant documentation.
- Search existing issues.
- Reduce the problem to a minimal example.
- Include the RuleGate package version.
- Remove credentials, tokens, private policy data, and personal information.

## Bug reports

Use the
[bug-report form](https://github.com/fotbiler-lab/rulegate/issues/new?template=bug-report.yml)
when behavior appears incorrect and can be reproduced.

Include package versions, target framework, operating system, a minimal
reproduction, expected behavior, and actual behavior.

## Feature requests

Use the
[feature-request form](https://github.com/fotbiler-lab/rulegate/issues/new?template=feature-request.yml)
for new capabilities or public API proposals.

Explain the underlying authorization problem rather than only suggesting an
API shape. This helps determine whether the request belongs in the core engine,
a provider integration, an SDK, the CLI, or application code.

## Documentation issues

Use the
[documentation form](https://github.com/fotbiler-lab/rulegate/issues/new?template=documentation.yml)
for missing, unclear, outdated, or incorrect documentation.

## Security vulnerabilities

Do not report vulnerabilities publicly.

Follow [SECURITY.md](SECURITY.md).

## Support model

RuleGate does not provide paid or commercial support, a service-level
agreement, or a guaranteed response time. Community questions, bug reports,
documentation improvements, and focused contributions are welcome through the
public repository processes above.
