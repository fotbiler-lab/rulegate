# Fotbiler RuleGate

A local-first, provider-independent and policy-driven authorization framework.

RuleGate is designed to combine:

- Role-Based Access Control (RBAC)
- Attribute-Based Access Control (ABAC)
- Context-Based Access Control (CBAC)
- Resource-Based Authorization

## Status

RuleGate is under active development and is not yet ready for production use.

## Core principles

- Local-first authorization
- Provider independence
- Default deny
- Fail closed
- Explicit and explainable decisions
- No arbitrary scripts in policy manifests
- Backend enforcement as the security boundary
- Extensible authorization requirements
- Strongly typed backend and frontend contracts

## Planned integrations

- ASP.NET Core
- Angular
- Keycloak
- OpenTelemetry
